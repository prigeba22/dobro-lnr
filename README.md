# Рядом · ЛНР

Локальная копия опубликованного сайта `[https://chat-bot-orpin-two.vercel.app/](https://dobro-lnr.onrender.com/#loyalty)`.

## Запуск

```powershell
npm install
npm run dev
```

После запуска откройте адрес, указанный в терминале (обычно `http://localhost:3000`).

## Где менять сайт

- `index.html` — основная страница, стили и JavaScript.
- `privacy.html` — страница обработки персональных данных.
- `assets/brand/` — шрифты и логотипы.
- `План октябрь.docx` — документ, доступный по ссылке на сайте.

После изменения `index.html` обновите страницу в браузере. Для остановки сервера нажмите `Ctrl+C` в терминале.

## Публикация

Проект содержит `render.yaml` и готов к публикации как Static Site через Render Blueprint. Команда сборки не требуется, а публикуемая папка — корень проекта (`.`).
